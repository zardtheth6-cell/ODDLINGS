# Environment / map notes

World coordinates: plaza at the origin, Mushroom Woods north (0, −330), Frostbite Fields east (330, 0),
Molten Valley south (0, 330), Cosmic Outlands floating west (~−380, 70, 0), 8 base plots on the diagonals (radius ~238).
Terrain surface sits at y ≈ 2 in meadows and y ≈ 0 in the plaza.

| Area | Key features |

| Paths | Cobblestone with slate borders, curb stones, lamp posts, signposts, branches to every base door |

| Cosmic Outlands | 6 floating islands with hanging crystals, light falls, orbiting rocks, glowing bridges, observatory, teleport pads, halo ring, portals |
