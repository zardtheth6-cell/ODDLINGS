# 04 — Characters and Creatures

Store character/creature concepts, visual sheets, silhouettes, proportions, palettes, rigs, animation lists, behaviors, abilities, and approved model references. Include front/side/back views when a design requires accurate 3D modeling.

Suggested subfolders: `CONCEPT_ART/`, `MODEL_REFERENCES/`, `RIGS_AND_ANIMATIONS/`, `TEXTURES/`.
