# AFTERHOURS Asset Approval and Import Checklist

## Asset intake
Every imported model, texture, audio file, animation, icon, font or effect must have:
- Asset name and stable project ID.
- Asset type and intended use.
- Creator/source and permission or license status.
- Roblox asset ID if uploaded.
- Poly/texture/audio budget where relevant.
- Required dependencies.
- Intended platform quality tier.
- Approval status and known limitations.

## Approval states
PROPOSED → REVIEW → APPROVED → INTEGRATED → VERIFIED. REJECTED assets must include a reason. Approval does not mean the asset is integrated or tested.

## Import checks
- Correct scale, orientation, pivot and origin.
- Intentional collision geometry with no invisible blockers.
- Appropriate mesh complexity and texture resolution.
- Correct UVs and material response under the game's lighting.
- No unauthorized external content.
- Correct rig compatibility and animation priority.
- Correct audio spatialization, mix and license.
- Mobile performance considered.

## Originality and rights
Do not use ripped assets, unlicensed music, copied game maps, stolen models or assets with unclear permissions. Keep source attribution and license evidence where required. Generated concept images are visual references, not production-ready models or proof of asset rights.

## Naming convention
Use descriptive stable prefixes: ENV_ environment, PROP_ props, CRE_ Creature, UI_ interface, SFX_ sound, VFX_ effects, ANIM_ animations.

## Reference-image status
The concept boards shown in the ChatGPT conversation are not automatically stored in this GitHub folder. Upload the actual image files before expecting Claude to inspect them from the repository. Never create fake image files or claim a reference is present when it is not.
