# 02 — Visual References

This folder is for actual visual files, not just written descriptions. Add approved reference images, generated concept art, moodboards, material examples, lighting examples, and visual comparison sheets here.

Suggested subfolders: `MOODBOARDS/`, `MAP_REFERENCES/`, `CHARACTER_REFERENCES/`, `UI_REFERENCES/`, `MATERIALS_AND_TEXTURES/`, `LIGHTING_AND_ATMOSPHERE/`.

Use descriptive filenames, for example `map_hub_daytime_reference_01.png`. Add a short note beside each image explaining exactly what Claude should take from it and what must not be copied. Reference images are not present yet because the new game's concept and art direction have not been chosen.
