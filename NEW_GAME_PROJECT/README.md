# AFTERHOURS — New Roblox Game Project

This is the independent AFTERHOURS workspace. It is separate from ODDLINGS. Do not reuse ODDLINGS scripts, mechanics, branding, maps or assets unless explicitly requested.

## Current project status
- Game: AFTERHOURS
- Genre: ultra-realistic-feeling horror exploration, stealth, survival and extraction
- Core modes: solo Explorer vs AI; cooperative Explorer expeditions; asymmetrical player-controlled Creature vs Explorers
- Players: target 1–4 Explorers; asymmetrical target 1 Creature vs 1–4 Explorers
- Danger: hybrid psychological/environmental horror and physical creatures
- Movement: walk, sprint, crouch, jump, slide, vault, lean, hide and stamina
- Visual target: extremely realistic environments, original creature designs, cinematic capture jumpscares and premium realistic UI
- Hard exclusion: no guns, shooting, ammunition, crosshairs, military HUD or shooter mechanics
- Voice chat: never required
- Current stage: concept/design package created; pre-production, not yet implemented or tested in Roblox Studio

## Working rules
- Treat written specifications as authoritative when a concept image contains errors.
- Keep planned, implemented and tested statuses separate.
- Build one polished vertical slice before expanding the game.
- Every system must work in solo and multiplayer where relevant.
- Test PC, mobile and controller.
- Keep the no-guns/no-shooter identity.
- Never claim completion without testing and evidence.
