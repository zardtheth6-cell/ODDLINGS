# New Roblox Game Project

This is a clean, separate workspace for the next Roblox game. It is intentionally independent of the previous ODDLINGS project. Do not copy ODDLINGS scripts, mechanics, branding, maps, or assets into this project unless the owner explicitly asks.

## How to use this workspace
1. Agree on the new game concept before producing game-specific assets.
2. Put approved visual references and generated reference images in `02_VISUAL_REFERENCES/`.
3. Keep the game design, world plan, characters, UI, systems, source code, and tests in their dedicated folders.
4. Claude should read this file and the relevant folder READMEs before starting work.
5. Keep a clear distinction between planned, implemented, and tested features.

## Folder guide
- `00_PROJECT_OVERVIEW` — decisions, scope, milestones, and project status
- `01_GAME_CONCEPT_AND_DESIGN` — core concept, gameplay loop, progression, economy, and full design document
- `02_VISUAL_REFERENCES` — reference pictures, moodboards, visual targets, and image prompts
- `03_WORLD_MAP_AND_ENVIRONMENT` — map layouts, terrain, buildings, lighting, and environment references
- `04_CHARACTERS_AND_CREATURES` — character concepts, creature sheets, rigs, animations, and references
- `05_UI_UX_AND_ICONS` — interface layouts, icons, HUD, menus, and shop references
- `06_GAMEPLAY_SYSTEMS` — mechanics specifications and system diagrams
- `07_AUDIO_AND_EFFECTS` — music direction, sound effects, and VFX references
- `08_ROBLOX_SOURCE_CODE` — scripts, modules, configuration, and code documentation
- `09_ASSETS_AND_MODELS` — approved models, textures, decals, and asset manifests
- `10_CLAUDE_PROMPTS_AND_TASKS` — master prompt, phase prompts, and task handoffs
- `11_TESTING_AND_BUGS` — test plans, results, bugs, and fixes
- `12_BUILDS_AND_RELEASES` — versioned place files and release notes
- `13_MARKETING_AND_PUBLISHING` — title, description, thumbnails, icons, banners, and launch checklist
